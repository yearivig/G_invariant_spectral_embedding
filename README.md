# G-Invariant Spectral Embedding: experiments

Code for the numerical experiments of *Group Invariant Spectral Embedding*
(Vigder, Hoyos, Thong, Andén, Kileel & Moscovich). The experiments of
Section 5 embed data with Algorithm 1 of the paper: $W_{ij} = K(x_i, x_j)$,
$L_{RW} = I - D^{-1}W$, and the eigenvectors of the smallest nonzero
eigenvalues.

| paper | folder | data, group, kernels |
|---|---|---|
| Section 3.5, Figure 2 | `experiments/so3_so2_convergence/` | SO(3) with SO(2) acting; Euclidean, minimum, integral (graph Laplacian at one point) |
| Section 5.1, Figure 4 | `experiments/3d_point_clouds/` | 3D point clouds, SO(3); Euclidean, minimum, integral, invariant features |
| Section 5.2, Figure 5 | `experiments/tomographic_images/` | tomographic images, SO(2); Euclidean, minimum, integral, invariant features |
| Section 5.3, Figure 7 | `experiments/spinning_objects/` | two spinning COIL-100 objects, SO(2); Euclidean, minimum, integral |

Each folder has its own README, `requirements.txt`, runner and `results/`
(outputs; not committed, except the results behind Figure 2), organised as
`scripts/` (entry points) and `tools/` (modules), plus `data/` (inputs) where
the data are external. Python 3.12 is recommended; all experiments were also
tested on Python 3.14, with identical results.

## Data

- Section 5.1: the Glucagon trajectory `data_3D.pkl` (not public), in
  `experiments/3d_point_clouds/data/`.
- Section 5.2: the projection images `projections-synth.pt` and their angles
  `output_main.csv` (not public), in `experiments/tomographic_images/data/`.
- Section 5.3: COIL-100, downloaded by the experiment's first script.
- Section 3.5: generated by the experiment; its results are committed.

## Running

```bash
bash run_submission_experiments.sh                 # all four, in the order of the paper
```

or each experiment on its own:

```bash
bash experiments/so3_so2_convergence/run_all.sh          # Figure 2, from saved results
bash experiments/3d_point_clouds/run_all.sh              # Figure 4
bash experiments/tomographic_images/run_all.sh           # Figure 5
(cd experiments/spinning_objects && bash run_all.sh)     # Figure 7 (long; see its README)
```

Outputs go to `results/` inside each experiment. For Section 3.5 the results
behind Figure 2 are committed (`so3_so2_P_1_00_results.pkl` and the figure
itself); the earlier outputs of Sections 5.1 and 5.2 were removed, since they
came from the code before its fixes to Algorithm 1.
