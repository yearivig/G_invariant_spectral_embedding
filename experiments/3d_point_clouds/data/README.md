# Data

Put the Glucagon trajectory here as `data_3D.pkl`: a pickle of an array of
shape `(num_frames, num_atoms, 3)`, the frames of the ψ-torsion rotation of the
19th residue. Atoms 800 onward hold the rotation movement used in Section 5.1.

The file is not public and is not in the repository; ask the authors for it.
